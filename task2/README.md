# task2 — Landing page

Макет лендинга выполнен по приложенному скриншоту в тёмной фиолетовой стилистике.

## Структура
- `index.html` — семантическая HTML-структура.
- `style.css` — все стили, Mobile First.
- `img/` — папка зарезервирована под локальные изображения; в этой версии графические объекты сделаны CSS-градиентами.

## Требования лабораторной
- 3 контрольные точки: до 767px, 768–1199px, от 1200px.
- CSS Grid используется для крупных блоков страницы и сетки карточек.
- Flexbox используется для навигации, кнопок, карточек и рядов.
- На мобильной ширине меню визуально превращается в гамбургер без JavaScript.
- Есть форма с полями Имя, Email, Сообщение и кнопкой Отправить.
- Есть состояния `:hover` и `:focus` и плавные `transition`.
- Не используется inline CSS и JavaScript.
